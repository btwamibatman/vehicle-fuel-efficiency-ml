# Start-stop и подробная трансмиссия: результаты расширения

Дата: 2026-11-14. Ветка: `khamza/start-stop-transmission`.
Исходная версия: `0ce27ed`. Это дополнительный feature experiment после завершённой
эндки, а не новый независимый test и не замена темы или источника данных.

## Результат

Оба дополнения снизили ошибки в проверенных вариантах. С полным набором признаков
лучшей по validation MAE стала ANN: **0.805409 MPG**, RMSE **1.197025 MPG**,
R² **0.962684**. Исходная ANN имела MAE 1.082715 MPG; снижение составляет
**25.61%**. Это наблюдение на прежнем validation с одним seed, без доверительных
интервалов, поэтому оно не доказывает такое же улучшение на новых автомобилях.

## Что добавлено и зачем

- `start_stop`: из исходного `startStop`. Y → 1, N → 0, неизвестное значение →
  missing с последующей train-only imputation. Система выключает двигатель на
  остановках; наличие системы является осмысленной характеристикой автомобиля.
- `transmission_detail`: полная очищенная строка `trany`, например `Automatic
  8-spd`, `Manual 6-spd` или обозначение CVT. Она **заменяет** грубую категорию
  Automatic/Manual/Other во втором расширенном варианте. Различия коробок теперь
  не теряются; отдельного числового признака количества передач не вводили.
- Категории кодируются one-hot на train; неизвестные категории на validation
  игнорируются encoder. Нет подгонки encoder/scaler на validation.

Все данные взяты из уже имеющегося `data/raw/vehicles.csv`: никаких новых
скачиваний, искусственных значений мощности/веса или внешних joins.
На train start-stop заполнен в 9,816 строках (5,419 Y, 4,397 N); у подробной
трансмиссии 33 категории. Число входов ANN: **40 → 41 → 72** после preprocessing.
Это увеличение размерности кодирования, не добавление 32 независимых измерений.

## Как обеспечена сопоставимость

До новых результатов записан `docs/feature_extension_protocol.json`:

1. Три заранее заданных варианта: original; +start-stop; +start-stop и подробная
   трансмиссия. Отдельного transmission-only варианта нет, поэтому его чистый
   отдельный эффект и взаимодействие признаков этим экспериментом не измерены.
2. Одинаковые исходные bytes, фильтры 2015+, seed 42 и упорядоченные row IDs:
   9,816 train / 2,080 validation / 2,079 ранее использованных holdout rows.
   Дополнительные поля присоединяются **после** исходного splitting по raw row ID;
   они не меняют определение duplicate groups и не пересоздают splits.
3. Все пять classical models используют фиксированные ранее выбранные параметры.
   Нового hyperparameter search нет. GroupKFold(5) выполняется только на train,
   с новым fit preprocessing внутри каждого fold. Сохранены все 75 fold scores.
4. ANN: по одному запуску на вариант, прежние hidden layers (64,32), ReLU,
   Adam lr=0.001, MSE на train-standardized target, batch 64, seed 42,
   cap 200 epochs, patience 20. Checkpoint — minimum validation MSE.
   Это **не** новый поиск четырёх архитектур и **не** ANN cross-validation.
5. Исходные результаты эндки сохранены побайтово. Для расширения используются
   отдельные подпапки `reports/results/endterm/feature_extension/` и
   `reports/figures/endterm/feature_extension/`.
6. Holdout не переоценивался. Существующая test-таблица относится только к старым
   моделям; у расширенных моделей нет нового test score.

## Validation MAE: контролируемое сравнение

Одинаковые 2,080 validation rows, единицы — US MPG, меньше лучше.

| Модель | Исходный вариант | + start-stop | + start-stop + подробная трансмиссия |
|---|---:|---:|---:|
| Baseline (mean) | 4.661760 | 4.661760 | 4.661760 |
| Linear Regression | 2.018650 | 1.993378 | 1.749138 |
| Ridge | 2.020510 | 1.995525 | 1.750653 |
| Decision Tree | 1.051024 | 0.997551 | 0.836948 |
| KNN | 1.092308 | 1.035577 | 0.834135 |
| Feedforward ANN | 1.082715 | 1.010398 | 0.805409 |

ANN выигрывает validation MAE полного варианта, KNN имеет MAE 0.834135,
дерево — 0.836948. Разница KNN/дерево мала; не заявляем статистическое превосходство.

## Поддерживающая проверка: training-only CV MAE

| Модель | Исходный вариант | + start-stop | Полный вариант |
|---|---:|---:|---:|
| Linear Regression | 1.985638 | 1.950735 | 1.717523 |
| Ridge | 1.985560 | 1.950895 | 1.719178 |
| Decision Tree | 1.089671 | 1.026267 | 0.842327 |
| KNN | 1.113729 | 1.058173 | 0.875070 |

Снижение ошибки видно и в этих training folds. Параметры были выбраны в прежнем
эксперименте на том же train, поэтому это поддерживающий контроль, а не новая
независимая оценка после model selection. Доверительные интервалы не вычислялись.

## Обучение ANN и overfitting

| Вариант | Входов | Best epoch | Epochs run | Train MAE | Validation MAE |
|---|---:|---:|---:|---:|---:|
| original | 40 | 113 | 133 | 0.946014 | 1.082715 |
| start_stop | 41 | 198 | 200 | 0.831200 | 1.010398 |
| start_stop_transmission | 72 | 134 | 154 | 0.655774 | 0.805409 |

Полный вариант восстановил epoch 134 и завершился на epoch 154. Разрыв train и
validation MAE около 0.150 MPG сохраняется; утверждать отсутствие overfitting
нельзя. Вариант только со start-stop достиг cap 200 (best 198), поэтому бюджет
обучения мог ограничить его результат. Дополнительных попыток после результатов
не запускали. Изменение входной размерности меняет initialization; это не
строгий причинный эксперимент с единственным изменённым фактором оптимизации.

## Воспроизведение исходного контроля и KNN ties

Исходная ANN повторила сохранённые predictions с абсолютной точностью 1e-10.
Для исторических classical artifacts сравнение идёт с новым original control
в текущем окружении. Ridge отличается от исторического MAE примерно на 0.0000022
MPG. Исторический KNN MAE 1.089423, текущий original control — 1.092308.
Проверены все 292 различающихся validation predictions: у каждого расстояния
до третьего и четвёртого соседей равны. Всего таких граничных ties — 1,329.
Поэтому результат чувствителен к выбору соседей при равных расстояниях, включая
различия окружения. Это не скрыто как улучшение от новых признаков.
Подробности: `historical_reconciliation.csv`, `knn_historical_ties.json`.

## Ограничения и честные выводы

- Validation уже использовался для прошлых решений и сейчас для checkpoint
  selection и сравнений. Это post-hoc development, не независимое подтверждение.
- Зафиксированные гиперпараметры могут быть неоптимальны для новых признаков;
  отсутствие retuning помогает отделить изменение признаков от нового поиска.
- Снижение prediction error не доказывает причинную экономию топлива от
  start-stop или определённой коробки. Признаки связаны с другими свойствами машин.
- Weight, horsepower, аэродинамика и реальные условия езды по-прежнему отсутствуют.
  Related make/model variants могут пересекать splits. EPA rating — не гарантия
  реального расхода. Тема, группа и источник не изменены.
- K-Means и PCA остаются анализом cylinders/displacement на том же train; их
  результаты не нужно выдавать за изменившиеся от новых supervised features.
- Презентация должна оставаться 10–15 слайдов на 12 минут. Обновлён outline;
  готовый slide deck этим изменением не создавался.

## Что открыть и какие команды выполнить

Основной отчёт: `notebooks/endterm/project.ipynb`.
Детальный эксперимент: `notebooks/endterm/05_feature_extension.ipynb`.
Краткая демонстрация реального validation-примера:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/feature_extension_walkthrough.py
.\.venv\Scripts\python.exe -m vehicle_efficiency.feature_extension --verify
.\.venv\Scripts\python.exe -m pytest -q
```

Без `--verify` модуль запускает полный предписанный эксперимент и сохраняет
результаты; при наличии завершённого результата отказывается перезаписывать его.
Для повторного обучения нужна отдельная чистая копия проекта без подпапки
результатов этого расширения. Исходные данные и родительские endterm artifacts
в такой копии должны соответствовать сохранённому протоколу. Не удаляйте текущие
результаты ради демонстрации: сохранённые модели уже доступны для inference.
